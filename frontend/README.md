# BOCADO_Polar — Frontend

React 19 + TypeScript + Vite + SWC. Consume el `api-gateway` del backend (`../backend`).

```bash
cp .env.example .env   # VITE_API_BASE_URL=http://localhost:8080/api/v1
npm install
npm run dev            # http://localhost:5173
```

Estructura, cuentas de prueba y scripts: ver el [README principal](../README.md).
